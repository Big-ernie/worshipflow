# WorshipFlow Product Specification

## Product thesis

WorshipFlow should feel like an instrument, not a media player. A worship musician should be able to shape atmosphere in real time without hunting through folders, DAW sessions or fixed backing tracks.

## Core user

Primary: keyboardists, guitarists, bassists, drummers, music directors, session musicians and producers serving gospel/worship environments.

Secondary: churches, worship leaders, prayer ministries, rehearsal teams and live-event producers.

## MVP job to be done

When the room needs musical atmosphere before, between or underneath songs, let me create it immediately, stay in key, shape the energy and move to the next moment without opening a DAW.

## Current MVP capabilities

- 12-key major/minor drone pad engine
- Smooth key crossfades
- Adaptive pad intensity
- Generated congregation ambience
- Worship moment presets
- Swell, impact, shimmer and sub drop FX
- Click track and tap tempo
- Keyboard shortcuts and Web MIDI
- Local presets and service setlists
- PWA shell and offline static caching

## Production priorities

1. Custom sample-based pad libraries
2. IndexedDB offline audio storage
3. Seamless loop points and configurable key crossfades
4. Layered crowd engine with intensity thresholds
5. Custom FX libraries
6. Supabase Auth, Storage and metadata sync
7. MIDI Learn
8. Richer setlists
9. WorshipFlow Live / MD Sync
10. Backing tracks, stems, cues and chord charts

## Product principles

1. Stage reliability beats feature count.
2. Any essential action should be reachable in one tap.
3. Key changes must sound musical, never abrupt.
4. Internet loss must not stop a service.
5. The interface must remain readable from a keyboard stand or floor rig.
6. African gospel worship should be a first-class use case, not an afterthought.
