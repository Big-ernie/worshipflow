Security by tenant, role and least privilege.

CRM Hub is designed so that each company sees only its own workspace data and each team member receives only the modules assigned to them.

Tenant isolation

Row-level security and workspace-aware permission checks separate customer records.

Role controls

Owner, admin, manager, sales, support and viewer roles can be customized per module.

Support access

Customer workspaces can grant explicit, time-limited support access rather than giving platform staff blanket access.

Operational controls

  • Automatic audit logging on core CRM record changes
  • Concurrency-safe quote numbering
  • Appointment conflict checks
  • WhatsApp secrets stored server-side
  • Per-workspace AI governance controls
  • Plan and trial enforcement

No claim of external security certification or independent penetration testing is made at this stage.
